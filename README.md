**Yellow Fever Surveillance Predictive Modelling
Project Overview**

This project applies Python and machine learning to a simulated yellow fever surveillance dataset containing approximately 5,000 records and 179 columns. It demonstrates data cleaning, exploratory data analysis, feature engineering, and classification modelling.

**Objectives**

Clean and prepare messy surveillance data.

Explore demographic, clinical, vaccination, and laboratory variables.

Develop and compare machine learning classification models.

Evaluate model performance using cross-validation and test-set metrics.

Examine feature importance.

**Machine Learning Models**

Logistic Regression

Decision Tree

Random Forest

Extra Trees

Gradient Boosting

Support Vector Classifier (SVC)

K-Nearest Neighbours (KNN)

Dummy Classifier (baseline)

**Tools**
Python, Pandas, NumPy, Matplotlib, Scikit-learn, and Joblib.

Target Variable

Latest sample final laboratory result

Binary classification: Positive (1) versus Negative (0). Inconclusive results are excluded.

**Disclaimer**

The dataset is simulated and intended for educational and portfolio purposes only. Model results do not represent real-world yellow fever surveillance performance and must not be used for clinical diagnosis or public health decisions.
